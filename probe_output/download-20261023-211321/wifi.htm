Setup:

Enable either Station OR Access Point mode, enabling both can cause performance issues.

If you want OnStep to connect to your home WiFi network, enable only Station mode and disable Access Point mode. If OnStep cannot connect to your home WiFi network it will automatically re-enable Station mode; this is useful when you are away at a dark site and/or to guard against becoming locked out.

If locked out of WiFi you can use the Arduino IDE to reset the ESP flash memory (and hence go back to defaults.) From the Arduino Tools menu, change Erase Flash 'Only Sketch' to Erase Flash 'All Flash Contents' and upload the WiFi-Bluetooth sketch again.
